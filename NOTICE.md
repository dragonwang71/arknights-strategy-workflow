## Published code

`strategy_workflow/timing.py` is an extraction of project-level candidate-planning logic developed with AI coding assistance. Its decision logic is retained; the module documentation is adapted for this standalone example. The tests are adapted from the corresponding project tests, with their import changed to the standalone package. The demo and its input are prepared specifically for this repository.

These files use the Python standard library. The synthetic example contains no real roster, game map, game assets, or executable battle plan. The design notes describe selected observations from local development; they are not an independently audited benchmark.
